# B to Bern documentation

B to Bern (B2B), by **Team Stregoni**, turns permitted company context into a
source-backed, human-reviewed Bern opportunity brief.

**Jury and users:** [start here](judges/README.md).

retain their original contents. Internal task prompts, recordings, source
snapshots and machine-specific access-status handoffs are intentionally excluded
from the submission package.
