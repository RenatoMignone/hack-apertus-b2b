# User workflows and cases

| Scenario | Expected behavior |
| --- | --- |
| New company needs | Enter permitted context; immediate preparation view; durable interpretation/research |
| Ambiguous or incomplete intent | Ask a focused blocking question; resume same run with the answer |
| Lay terminology | Preserve full request and expand reviewed aliases; do not force uncertain concepts |
| Source-backed match | Show capability, company fit, exact passage, URL and source status |
| Adjacent opportunity | Label uncertainty and require evidence for the underlying capability |
| Missing contacts or expertise | Leave fields unknown, retain useful supported unit information |
| No reliable match | State coverage and evidence gaps; do not infer no expert exists |
| Rewrite request | Reuse the frozen pack and reassess wording |
| Changed company/focus | New input/research revision; previous report remains read-only |
| Review/export | Review all cards, keep one, approve exact hashes, export kept content |
| Reopen after leaving | Observe durable case/run; no duplicate run and no implicit cancellation |
| Optional manual plans/history | Explicit confirmation/opt-in and capability gates |

A permitted fictional test request:

> HelioSense is a fictional European company developing wearable glucose sensors.
> It is exploring an R&D presence in Bern and seeks sensing algorithms, biomedical
> engineering collaborators and evaluation infrastructure. Find supported research
> capabilities, separate direct fit from adjacent possibilities, and state unknown
> contacts or collaboration availability. This is a test scenario, not a real plan.

Compare “glucose sensor”, “CGM” and “continuous glucose monitoring” while keeping
the same intent. Test an unrelated commodity-trading request and explicit exclusions.
Inspect evidence rather than expecting identical named results across incomplete
captures. For the scripted HelioSense demo use the [walkthrough](../judges/DEMO.md);
for scored quality use independently reviewed [evaluation](EVALUATION.md) labels.
